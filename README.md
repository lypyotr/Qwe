# Зарплата

Личный рабочий кабинет: дневник выполненных работ, расчётные периоды, расходы, цели, статистика и сообщения.

## Тестовый запуск на Windows

Запустите `test_launch.cmd`. Нужен Python 3.9 или новее; дополнительные пакеты и сборка не требуются. Браузер откроется автоматически. Для остановки нажмите Ctrl+C в окне запуска.

Локальная версия подключается к существующему Supabase: изменения после входа синхронизируются с основным аккаунтом. Локальные данные браузера для `127.0.0.1` хранятся отдельно от GitHub Pages. Регистрация service worker в локальном запуске отключена, чтобы изменения файлов были видны после обновления страницы.

## Что изменено

- Общая навигация: боковое меню на компьютере, пять основных разделов внизу на телефоне, поиск разделов через кнопку или Ctrl+K.
- Дневник: переключение периода стрелками, кнопка «Сегодня», последний выбранный день каждого периода сохраняется на устройстве отдельно для каждого аккаунта. При первом открытии выбирается сегодня либо первый день периода.
- Архив и сообщения: поиск месяцев, годов, друзей по имени и ID; копирование своего ID; группы с явным выбором участников.
- Чат: защита от повторных нажатий отправки, текст остаётся при ошибке. Черновики текста, карточек работ, ответов и редактирования сохраняются после перезапуска на этом устройстве отдельно для каждого аккаунта и чата. При уходе из чата запись голоса отменяется; уже отправляемый файл сохраняет исходного получателя. После возвращения сети загрузка медиа повторяется.
- Доступность: масштабирование страницы, видимый фокус, клавиатурное управление, подписи полей, управление фокусом и Escape в диалогах, учёт уменьшения анимации.
- Исправлено открытие архивных месяцев вне диапазона первоначального списка, привязка отмены удаления к исходному периоду и выбор ближайшей даты выплаты по существующему графику 7/22.
- Итоги: переключатель «До расходов / На руки» учитывает выбранный налог; отмена удаления восстанавливает и данные, и состояние переключателя налога.
- Обновления PWA: новая версия ожидает нажатия «Обновить». Во время отправки, загрузки файла и записи голоса обновление блокируется. Перед перезагрузкой вкладки сохраняют свои черновики.

На телефоне Enter добавляет новую строку сообщения. На компьютере Enter отправляет, Shift+Enter переносит строку. Кнопка отправки доступна в обоих режимах.

## Файлы

- `index.html` — существующие экраны, расчёты, авторизация и синхронизация.
- `workspace.css` — оформление и адаптивная компоновка.
- `workspace.js` — навигация, поиск разделов и доступность.
- `messenger-v2.js` — сообщения и группы.
- `sw.js` — кэш установленного приложения; версия обновлена вместе с ресурсами.

Схема базы и форматы расчётных данных не менялись. Черновики и выбранные дни хранятся как отдельные локальные настройки браузера; они не синхронизируются между устройствами.

## Проверки

После установки Playwright и Chromium:

```sh
node scripts/check-inline-js.mjs
node scripts/smoke.mjs
node scripts/workspace-test.mjs
node scripts/pwa-test.mjs
node scripts/crypto-test.mjs
```

Тесты интерфейса и PWA блокируют внешние запросы и не меняют реальные аккаунты. Они проверяют диалоги, клавиатуру, календарь на шести ширинах в двух темах, расчёт и отмену, сохранение черновиков, отправку, восстановление медиа и обновление двух вкладок с последующим офлайн-запуском. Проверки включены в CI; коммит исправлений не использует `[skip ci]`.

Реальный вход и синхронизацию, запуск `.cmd` в Windows и Safari на iPhone нужно проверить отдельно. EXE не собирался.

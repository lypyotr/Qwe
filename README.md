# Зарплата

Личный рабочий кабинет: дневник выполненных работ, расчётные периоды, расходы, цели, статистика и сообщения.

## Тестовый запуск на Windows

Запустите `test_launch.cmd`. Нужен Python 3.9 или новее; дополнительные пакеты и сборка не требуются. Браузер откроется автоматически. Для остановки нажмите Ctrl+C в окне запуска.

Локальная версия подключается к существующему Supabase: изменения после входа синхронизируются с основным аккаунтом. Локальные данные браузера для `127.0.0.1` хранятся отдельно от GitHub Pages. Регистрация service worker в локальном запуске отключена, чтобы изменения файлов были видны после обновления страницы.

## Что изменено

- Общая навигация: боковое меню на компьютере, пять основных разделов внизу на телефоне, поиск разделов через кнопку или Ctrl+K.
- Дневник: переключение периода стрелками, кнопка «Сегодня», автоматически выбранный день, более крупные поля количества и цены.
- Архив и сообщения: поиск месяцев, годов, друзей по имени и ID; копирование своего ID; группы с явным выбором участников.
- Чат: защита от повторных нажатий отправки, текст остаётся при ошибке, черновики между чатами в памяти текущей страницы, обновление групп. При уходе из чата запись голоса отменяется; уже отправляемый файл сохраняет исходного получателя.
- Доступность: масштабирование страницы, видимый фокус, клавиатурное управление, подписи полей, управление фокусом и Escape в диалогах, учёт уменьшения анимации.
- Исправлено открытие архивных месяцев вне диапазона первоначального списка, привязка отмены удаления к исходному периоду и выбор ближайшей даты выплаты по существующему графику 7/22.

На телефоне Enter добавляет новую строку сообщения. На компьютере Enter отправляет, Shift+Enter переносит строку. Кнопка отправки доступна в обоих режимах.

## Файлы

- `index.html` — существующие экраны, расчёты, авторизация и синхронизация.
- `workspace.css` — оформление и адаптивная компоновка.
- `workspace.js` — навигация, поиск разделов и доступность.
- `messenger-v2.js` — сообщения и группы.
- `sw.js` — кэш установленного приложения; версия обновлена вместе с ресурсами.

Схема базы и форматы сохранённых данных не менялись. Финальные проверки, запуск приложения и сборка EXE не выполнялись по просьбе владельца. Работу с реальным аккаунтом и отображение в браузере необходимо оценить при тестовом запуске.
